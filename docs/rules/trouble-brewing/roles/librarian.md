# 圖書管理員 librarian

鎮民｜首夜｜資訊

**能力**：在你的首個夜晚，你會得知兩名玩家和一個外來者角色：這兩名玩家之一是該角色（或者你會得知沒有外來者在場）。

## 操作
1. 選一名外來者（或可被當作外來者的玩家）放「外來者」，另選任一玩家放「錯誤」。
2. 喚醒，指向這兩人，展示「外來者」那位的角色；場上沒有外來者時比「0」。

## 測試案例
- 聖徒與男爵，指定聖徒 → 得知「兩人之一是聖徒」
- 唯一的外來者是陌客，說書人不把陌客當作外來者 → 得知 0
- 酒鬼（以為自己是僧侶）與送葬者 → 得知「兩人之一是**酒鬼**」，不是僧侶

## 規則細節
- 酒鬼是外來者，展示的是「酒鬼」本身。
- 「0」是合法資訊；但外來者明顯存在時給 0，等於暗示他中毒。

## 毒醉
可給錯的玩家或角色，原則上仍展示一個外來者角色；少數情況可用 0 混淆。

## 登記
- 陌客可不被當作外來者（唯一外來者是陌客時可給 0）。
- 間諜可被當作外來者。
