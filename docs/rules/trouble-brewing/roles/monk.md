# 僧侶 monk

鎮民｜每晚*（首夜除外）｜保護

**能力**：每個夜晚*，你要選擇除你以外的一名玩家：當晚惡魔的負面能力對他無效。

## 操作
1. 喚醒，讓他指一名**其他**玩家；指自己就搖頭請他重選。
2. 在目標旁放「保護」。
3. 惡魔攻擊受保護者時不死亡；黎明宣布無人死亡，不說明原因。
4. 黎明移除「保護」。

## 測試案例
- 保護占卜師，小惡魔攻擊占卜師 → 今晚無人死亡
- 保護鎮長，小惡魔攻擊鎮長 → 鎮長的轉移死亡不觸發，今晚無人死亡
- 保護小惡魔，小惡魔自殺 → 無事發生，小惡魔存活，**不傳位**

## 規則細節
- 不能選自己。
- 保護到當晚黎明為止。
- 只擋惡魔的能力，**不擋處決**。

## 毒醉
不放「保護」標記，沒有保護效果。
