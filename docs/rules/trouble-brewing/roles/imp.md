# 小惡魔 imp

惡魔｜每晚*（首夜除外）

**能力**：每個夜晚*，你要選擇一名玩家：他死亡。如果你以這種方式自殺，一名爪牙會變成小惡魔。

## 操作
1. 第二夜起喚醒，讓他指一名玩家（存活或死亡皆可）。
2. 目標存活、可被殺且小惡魔未毒醉 → 放「死亡」，黎明宣布。
3. 自殺時：一名存活爪牙換成小惡魔，喚醒新小惡魔告知「你是」＋小惡魔。

## 測試案例
- 小惡魔被處決，紅唇女郎不接任 → 善良獲勝
- 自殺，場上有存活的投毒者（無紅唇女郎）→ 投毒者變成小惡魔，**當晚不再行動**
- 自殺，存活 ≥5 人且紅唇女郎健康 → 由紅唇女郎接任
- 自殺但被僧侶保護 → 無事發生，不傳位
- 選擇已死的玩家 → 今晚無人死亡（可用來偽裝士兵或僧侶）
- 攻擊士兵 → 今晚無人死亡，不能改選

## 規則細節
- 首夜不行動；7 人以上首夜會得知爪牙與 3 個偽裝（見 `../setup.md`）。
- 新小惡魔不會補得首夜的互認資訊與偽裝。
- 毒醉時攻擊無效，不放「死亡」標記；**毒醉時自殺也無效**，不死亡也不傳位（重要細節頁：中毒的惡魔攻擊不會有人死亡）。
- 自殺時有多名存活爪牙且紅唇女郎不接任：**由說書人選擇**接任者，系統可提供隨機預設（Olalall 交給說書人；auto-dm 隨機）。
- 自殺時沒有存活爪牙：無人接任，惡魔死亡，善良獲勝。
- 一般爪牙接任**沒有人數門檻**，5 人門檻只限紅唇女郎的能力。（auto-dm 對所有接任都套用 5 人門檻，這是它的錯誤，不要照抄。）
