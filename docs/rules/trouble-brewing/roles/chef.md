# 廚師 chef

鎮民｜首夜｜資訊

**能力**：在你的首個夜晚，你會得知場上鄰座的邪惡玩家有多少對。

## 操作
喚醒，用手勢比出相鄰邪惡玩家的對數。

## 測試案例
- 沒有邪惡玩家相鄰 → 0
- 小惡魔與男爵相鄰，另一處投毒者與紅唇女郎相鄰 → 2
- 三名邪惡玩家連續相鄰，另一處兩名邪惡相鄰 → 3（連續 n 人算 n−1 對）
- 陌客坐在小惡魔與投毒者之間 → 預設給 0 或 2（同一次判定中陌客陣營應一致）

## 規則細節
- 座位是環狀的，首尾相接。
- 不要求存活；中途產生的廚師也計入死者。

## 毒醉
可給錯誤的數字。

## 登記
- 間諜可被當作善良，陌客可被當作邪惡。
- 同一次判定中，同一個人的陣營要一致，不要在左右兩對中給不同陣營。
