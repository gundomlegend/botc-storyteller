# 聖徒 saint

外來者｜死於處決時觸發

**能力**：如果你死於處決，你的陣營落敗。

## 操作
聖徒因處決死亡 → 宣布遊戲結束，邪惡獲勝。

## 測試案例
- 7 人存活，聖徒 4 票成為最高票且無其他更高票 → 處決，邪惡獲勝
- 聖徒被小惡魔夜殺 → 遊戲繼續
- 聖徒中毒時被處決 → 遊戲繼續
- 聖徒被獵手選中 → 不觸發（獵手只殺惡魔）

## 規則細節
- 必須「因處決而死亡」才觸發；處決了但沒死不觸發。
- 已死亡的聖徒再次被處決 → **不觸發**（能力條件是「死於處決」，已死者不會再死）。auto-dm 只檢查「被處決」而未檢查死亡，與規則文字不符，不要照抄。

## 毒醉
能力失效，被處決不會落敗。
