# 管家 butler

外來者｜每晚（含首夜）｜投票限制

**能力**：每個夜晚，你要選擇除你以外的一名玩家：明天白天，只有他投票時你才能投票。

## 操作
1. 喚醒，讓他指一名**其他**玩家，放「主人」。
2. 白天投票時，管家只能在主人舉手、或主人的票已被計算後舉手。

## 標記
- 主人：黃昏或管家死亡、離場時移除。

## 測試案例
- 主人舉手投票 → 管家可以一起投
- 主人沒舉手 → 管家不能投
- 兩人都舉手，計票前主人放手 → 管家也必須放手
- 管家已死亡 → 沒有限制，用亡魂票隨時可投

## 規則細節
- 不能選自己；能力不強制他投票。
- **違規投票仍然計票**，說書人不公開處罰，事後私下提醒即可。系統只提醒，不阻擋。
- 計票先後與座位無關。主人坐在管家後面時，建議主人提前舉手；管家的票已被計算後主人才放手，管家的票仍有效。
- 主人已死亡：主人沒有亡魂票時無法投票，管家也就投不了。

## 毒醉
不放「主人」標記，管家可自由投票。
