# 酒鬼 drunk

外來者｜被動｜設置影響

**能力**：你不知道你是酒鬼。你以為你是一個鎮民角色，但其實你不是。

## 設置
1. 酒鬼不放進抽袋，改放一個額外的鎮民標記；抽到的玩家實際是酒鬼。
2. 魔典上在該鎮民旁放「是酒鬼」。
3. 他以為的鎮民，不應同時由其他玩家持有。

## 操作
照他以為的鎮民讓他行動：會在夜晚醒來就喚醒他；會得到資訊就給（通常是錯誤的）資訊；能力永遠不生效。

## 測試案例
- 以為自己是士兵，被小惡魔攻擊 → 死亡
- 以為自己是共情者，坐在邪惡玩家旁 → 可得知 0，隔晚可得知 1
- 以為自己是守鴉人，夜晚被殺後選聖徒 → 可得知「投毒者」
- 以為自己是送葬者，占卜師被處決 → 可得知錯誤的角色
- 以為自己是廚師，提名貞潔者 → 不觸發（酒鬼是外來者）

## 規則細節
- 資訊「不可靠」而非「必定錯誤」；說書人可偶爾給正確資訊，避免他察覺。例如酒鬼守鴉人查自己時，應給他以為的角色。
- 以為自己是獵手、僧侶、鎮長等時，這些能力永遠無效。
- 送葬者、守鴉人、圖書管理員看到的是「酒鬼」。
- 酒鬼不是醉酒狀態，兩者無關；他的錯覺也不會因毒醉而改變。
- 能被說書人「改變認知」的範圍只限他以為的角色（例如可以讓他以為自己換成另一個鎮民）。

## 實作備註
- 目前專案開局時**隨機**指定他以為的鎮民；規則上這是說書人可以刻意選擇的，建議改成「隨機預設、說書人可修改」。
