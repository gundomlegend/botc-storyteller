# 獵手 slayer

鎮民｜白天｜每局一次

**能力**：每局遊戲限一次，你可以在白天時公開選擇一名玩家：如果他是惡魔，他死亡。

## 操作
1. 獵手公開宣布並指定目標（可給 1–2 分鐘討論）。
2. 目標是存活的惡魔 → 宣布死亡；否則宣布無事發生。
3. 無論結果，在獵手旁放「失去能力」（毒醉時也放）。
4. 有人假裝是獵手 → 配合演出，宣布無事發生。

## 測試案例
- 選中小惡魔（無紅唇女郎接任）→ 小惡魔死亡，善良獲勝
- 選中陌客，被當作小惡魔 → 陌客死亡，遊戲繼續
- 小惡魔假裝獵手選紅唇女郎 → 無事發生
- 選中已死的小惡魔 → 無事發生

## 規則細節
- 白天任何時間都能用，但必須公開。
- 用過一次就失去能力，不論是否毒醉、是否命中。
- 惡魔被殺時，存活 ≥5 人且紅唇女郎健康，她會接任。

## 毒醉
能力用掉但無效。

## 登記
陌客可被當作惡魔而被殺死。
