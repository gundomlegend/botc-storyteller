# 紅唇女郎 scarletwoman

爪牙｜惡魔死亡時觸發

**能力**：如果大於等於五名玩家存活時（旅行者不計算在內）惡魔死亡，你變成那個惡魔。

## 操作
1. 惡魔死亡時，計算**死亡前**的存活人數（不含旅行者）。
2. ≥5 人 → 她變成小惡魔，遊戲繼續；<5 人 → 不觸發。
3. 當晚喚醒她，告知「你是」＋小惡魔。

## 測試案例
- 死亡前 5 人存活（小惡魔、紅唇女郎、男爵、兩名鎮民），小惡魔被處決 → 她變成小惡魔，遊戲繼續
- 死亡前 4 人存活，小惡魔被處決 → 善良獲勝
- 死亡前 7 人存活但其中 3 人是旅行者，小惡魔被處決 → 只算 4 人，善良獲勝
- 她變成小惡魔前後，占卜師查她 → 之前「否」，之後「是」

## 規則細節
- 處決、獵手、夜晚自殺都適用。
- 小惡魔自殺且條件成立、她能力正常時，**必須由她接任**。
- 變成惡魔前不被當作惡魔；變成後在各方面都是惡魔（被處決則善良勝、每晚殺人）。
