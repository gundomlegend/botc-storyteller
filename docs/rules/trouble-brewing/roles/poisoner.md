# 投毒者 poisoner

爪牙｜每晚（含首夜）

**能力**：每個夜晚，你要選擇一名玩家：他在當晚和明天白天中毒。

## 操作
1. 喚醒，讓他指一名玩家，放「中毒」。
2. 中毒者照常行動，能力不生效；資訊類可給錯誤資訊。
3. 黃昏移除「中毒」。

## 標記
- 中毒：持續到下個黃昏；投毒者死亡、離場或換角色時立即移除。投毒者自己毒醉時不放。

## 測試案例
- 毒獵手，隔天獵手射小惡魔 → 無事發生，獵手失去能力
- 中毒的共情者坐在兩名邪惡之間 → 可得知 0；隔晚解毒 → 得知 2
- 中毒的調查員 → 可得知「兩人之一是男爵」而兩人都不是爪牙
- 中毒的聖徒被處決 → 遊戲繼續
- 毒鎮長後，投毒者變成小惡魔 → 鎮長立即解毒

## 規則細節
- 中毒期間用掉的「每局一次」能力無法再用。
- 和惡魔選同一目標，下毒等於浪費。
- 毒惡魔可讓當晚無人死亡（邪惡可用來掩護）。
- **可以毒自己，也可以毒死者**（規則未禁止即可做；auto-dm 也不限制目標）。
