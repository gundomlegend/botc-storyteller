# 共情者 empath

鎮民｜每晚（含首夜）｜資訊

**能力**：每個夜晚，你會得知與你鄰近的兩名存活玩家中邪惡玩家的數量。

## 操作
喚醒，比出 0、1 或 2。

## 測試案例
- 左右是士兵與僧侶 → 0
- 原本的鄰座都死了，往外找到的存活鄰居是圖書管理員與一名邪惡玩家 → 1
- 只剩共情者、小惡魔、男爵存活 → 2
- 鄰座今晚剛被小惡魔殺死 → 跳過他，改看同方向下一位存活玩家

## 規則細節
- 以**黎明時**的狀態為準。
- 跳過死者，取左右各自方向上最近的存活玩家。
- 只得知數量，不知道是誰。

## 毒醉
可給錯誤的數字，每晚可以不同。

## 登記
- 間諜可被當作善良（數字少算）。
- 陌客可被當作邪惡（數字多算）。
