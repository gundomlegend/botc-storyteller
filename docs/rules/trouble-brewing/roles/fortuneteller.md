# 占卜師 fortuneteller

鎮民｜每晚（含首夜）｜資訊

**能力**：每個夜晚，你要選擇兩名玩家：你會得知他們之中是否有惡魔。會有一名善良玩家始終被你的能力當作惡魔。

## 操作
1. 首夜準備時，在一名**善良**玩家旁放「干擾項」（可以是占卜師自己）。
2. 每晚喚醒，讓他指兩人；其中有惡魔或干擾項就點頭，否則搖頭。

## 標記
- 干擾項：占卜師死亡或離場時移除。

## 測試案例
- 鎮長＋送葬者 → 否
- 小惡魔＋共情者 → 是
- 存活的小惡魔＋已死亡的小惡魔 → 是
- 自己＋身為干擾項的聖徒 → 是

## 規則細節
- 可選任意兩人，包括自己與死者；已死的惡魔仍回答是。
- 干擾項整局固定；若干擾項變成邪惡，重新選一名善良玩家。
- 酒鬼以為自己是占卜師時，**不設**干擾項（他沒有這個能力）。
- 干擾項死亡後**仍然有效**，選到他照樣回答「是」（auto-dm 與 Olalall 都不檢查干擾項存活）。

## 毒醉
可給錯誤的是／否。

## 登記
陌客可被當作惡魔（這和干擾項是兩回事）。
