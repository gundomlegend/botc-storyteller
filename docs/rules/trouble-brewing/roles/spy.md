# 間諜 spy

爪牙｜每晚（含首夜）｜登記

**能力**：每個夜晚，你能查看魔典。你可能會被當作善良陣營、鎮民角色或外來者角色，即使你已死亡。

## 操作
1. 每晚喚醒，讓他看魔典，看多久由他決定。
2. 被探查時，由說書人決定這一次他被當作什麼。
3. 夜晚順序位置見 `../night-order.md`。

## 測試案例
- 洗衣婦得知「僧侶或間諜之一是守鴉人」，間諜被當作守鴉人 → 資訊成立
- 間諜坐在小惡魔與共情者之間：對廚師當作邪惡 → 廚師得知 1；同晚對共情者當作善良 → 共情者得知 0
- 間諜被當作鎮民，提名貞潔者 → 間諜被處決；當晚被當作酒鬼 → 送葬者得知酒鬼

## 規則細節
- 魔典會顯示陣營（角色標記倒放表示陣營與初始不同）。
- 說書人**不可**藉由改動魔典向間諜傳遞額外資訊。
- 說書人在魔典以外的筆記，間諜看不到。
- 惡魔的偽裝角色，若放在魔典上間諜就看得到。
- 被當作某鎮民或外來者時**不獲得**該能力。
- 死後仍有效；是唯一能觸發貞潔者的邪惡角色。

## 毒醉
展示給他看的魔典可以有誤。

## 實作備註
目前 `SpyHandler` 會產生魔典快照，並在毒醉時標記 `canLie`，符合規則。
