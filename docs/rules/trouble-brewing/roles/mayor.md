# 鎮長 mayor

鎮民｜被動

**能力**：如果只有三名玩家存活且白天沒有人被處決，你的陣營獲勝。如果你在夜晚即將死亡，可能會有一名其他玩家代替你死亡。

## 操作
1. 惡魔攻擊鎮長時，說書人決定鎮長死亡，或改由另一名玩家死亡。
2. 白天結束時，若恰好 3 人存活且當天無人被處決 → 善良獲勝。

## 測試案例
- 鎮長被攻擊，死亡轉給守鴉人；隔天剩 3 人存活，無人處決 → 善良獲勝
- 剩 3 人存活，唯一兩次提名平票 → 平票＝無處決 → 善良獲勝
- 剩 3 人存活，有人被處決 → 不觸發
- 鎮長中毒，剩 3 人存活且無處決 → 不觸發

## 規則細節
- 勝利在白天結束時判定。
- 轉移死亡由說書人決定，**可以不轉移**。
- 轉給不會死的對象（士兵、受保護者、已死玩家）→ 今晚無人死亡；不宜常用。
- 代死者的死因視同惡魔擊殺。

## 毒醉
既不會勝利，也不能轉移死亡。

## 待確認
- 「處決了但無人死亡」是否算當天有處決。核心規則指出處決與死亡不同，推定**算有處決**，鎮長不勝利。
