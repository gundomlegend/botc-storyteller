# 送葬者 undertaker

鎮民｜每晚*（首夜除外）｜資訊

**能力**：每個夜晚*，你會得知今天白天死於處決的玩家的角色。

## 操作
1. 白天有人**死於處決**時，在他的角色旁放「死於今日」（不論送葬者是否毒醉）。
2. 夜晚喚醒送葬者，展示該角色。
3. 當天無人死於處決：不喚醒，或喚醒但不展示。開局前決定用哪一種並保持一致。

## 測試案例
- 鎮長被處決 → 展示鎮長
- 以為自己是貞潔者的酒鬼被處決 → 展示**酒鬼**
- 間諜被處決，當晚被當作管家 → 展示管家
- 今天無人被處決 → 不喚醒

## 規則細節
- 只算「死於處決」；其他死因不算，處決了但沒死也不算。
- 只得知角色，不知道陣營。
- 因提名貞潔者而被處決的玩家也算。
- 首夜不行動。

## 毒醉
可展示錯誤的角色；「死於今日」標記照常放。

## 登記
間諜、陌客展示說書人當時決定的被當作角色。
