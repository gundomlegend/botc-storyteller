# 調查員 investigator

鎮民｜首夜｜資訊

**能力**：在你的首個夜晚，你會得知兩名玩家和一個爪牙角色：這兩名玩家之一是該角色（或者你會得知沒有爪牙在場）。

## 操作
1. 選一名爪牙（或可被當作爪牙的玩家）放「爪牙」，另選任一玩家放「錯誤」。
2. 喚醒，指向這兩人，展示「爪牙」那位的角色。

## 測試案例
- 男爵與鎮長，指定男爵 → 得知「兩人之一是男爵」
- 間諜與投毒者，指定間諜 → 得知「兩人之一是間諜」
- 陌客與小惡魔，陌客被當作投毒者 → 得知「兩人之一是投毒者」

## 規則細節
- 唯一爪牙是間諜且不被當作爪牙 → 得知 0。

## 毒醉
可給錯的玩家或角色，但仍應展示一個爪牙角色。

## 登記
- 陌客可被當作爪牙。
- 間諜可不被當作爪牙。
