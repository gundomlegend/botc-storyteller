# 守鴉人 ravenkeeper

鎮民｜夜晚死亡時觸發｜資訊

**能力**：如果你在夜晚死亡，你會被喚醒，然後你要選擇一名玩家：你會得知他的角色。

## 操作
在夜晚死亡時喚醒他，讓他指任一玩家（存活或死亡皆可），展示該玩家的角色。

## 測試案例
- 被小惡魔殺死，選擇共情者 → 得知共情者
- 小惡魔攻擊鎮長，死亡轉移到守鴉人；他選擇已死的陌客，陌客被當作紅唇女郎 → 得知紅唇女郎
- 白天被處決 → 不觸發

## 規則細節
- 夜晚因**任何原因**死亡都觸發；白天死亡不觸發。
- 毒醉的守鴉人、以為自己是守鴉人的酒鬼，夜晚死亡時**仍要喚醒**並讓他選擇。
- 只得知角色，不知道陣營。
- 選到酒鬼時展示「酒鬼」本身。

## 毒醉
仍喚醒，可展示錯誤的角色。

## 登記
間諜、陌客展示說書人決定的被當作角色。
