# 貞潔者 virgin

鎮民｜首次被提名時｜白天

**能力**：當你首次被提名時，如果提名你的玩家是鎮民，他立刻被處決。

## 操作
1. 首次被提名時，無論結果都在貞潔者旁放「失去能力」（毒醉時也放）。
2. 提名者是鎮民：立即宣布處決，**不投票**，白天結束。
3. 提名者不是鎮民：照常投票。

## 測試案例
- 洗衣婦首次提名貞潔者 → 洗衣婦被處決，白天結束
- 以為自己是廚師的酒鬼首次提名 → 無事，貞潔者失去能力，照常投票
- 第二次被鎮民提名 → 無事，照常投票
- 貞潔者提名自己 → 貞潔者被處決（他是鎮民）

## 規則細節
- 只看「首次」被提名。
- 提名者是外來者、爪牙、惡魔 → 照常投票；酒鬼是外來者，不觸發。
- 間諜被當作鎮民時可觸發，是唯一能觸發的邪惡角色。
- 提名者被處決但不會死（例如有保護）→ 宣布處決、不說明原因，白天仍結束。
- 死者不能提名，所以不會觸發。

## 毒醉
能力不生效、不處決，但仍算已被首次提名（放「失去能力」）。

## 登記
間諜可被當作鎮民而觸發。
