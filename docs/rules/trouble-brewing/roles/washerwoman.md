# 洗衣婦 washerwoman

鎮民｜首夜｜資訊

**能力**：在你的首個夜晚，你會得知兩名玩家和一個鎮民角色：這兩名玩家之一是該角色。

## 操作
1. 選一名鎮民（或可被當作鎮民的玩家）放「鎮民」，另選任一玩家放「錯誤」。
2. 喚醒，指向這兩人，展示「鎮民」那位的角色。

## 測試案例
- 廚師與守鴉人，指定廚師 → 得知「兩人之一是廚師」
- 小惡魔與貞潔者，指定貞潔者 → 得知「兩人之一是貞潔者」（錯誤標記可落在邪惡玩家）
- 間諜與紅唇女郎，間諜被當作守鴉人 → 得知「兩人之一是守鴉人」

## 規則細節
- 永遠不會得知「沒有鎮民」。
- 5 人局有男爵時，可能只能指向洗衣婦自己，等於暗示男爵在場；說書人應避免這種配置。

## 毒醉
可給錯的玩家、錯的角色或兩者皆錯，但**仍要展示一個鎮民角色**。

## 登記
間諜可被當作鎮民。
