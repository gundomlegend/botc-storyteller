# 陌客 recluse

外來者｜被動｜登記

**能力**：你可能會被當作邪惡陣營、爪牙角色或惡魔角色，即使你已死亡。

## 操作
每當有能力或規則探查、影響陌客的陣營或角色時，由說書人決定這一次他被當作什麼。

## 測試案例
- 獵手選陌客，被當作小惡魔 → 陌客死亡，獵手以為殺了惡魔
- 共情者坐在陌客旁：這晚當作邪惡 → 1；下一晚當作善良 → 0
- 調查員看陌客與聖徒，陌客被當作紅唇女郎 → 得知「兩人之一是紅唇女郎」
- 陌客被處決，被當作小惡魔 → 送葬者得知小惡魔
- 陌客坐在小惡魔與另一名邪惡玩家之間，真實對數是 2 → 說書人可給 0
- 唯一外來者是陌客 → 圖書管理員可得知 0

## 規則細節
- 每次探查分開決定，同一夜不同能力可得到不同結果。
- 陣營與角色分開判定。
- 被當作某爪牙或惡魔時**不獲得**該能力，真實陣營仍是善良。
- 死後仍有效。

## 相關角色
可被當作：占卜師的惡魔、調查員的爪牙、共情者與廚師的邪惡、送葬者與守鴉人看到的爪牙或惡魔、獵手的惡魔。
