# 核心規則

## 總則

- 規則沒禁止的就可以做：提名自己、在自己的提名中投票、惡魔攻擊死者、說謊、死者發言。
- 角色能力與核心規則衝突時，以角色能力為準。
- 能力文字有「選擇」由玩家決定，沒有則由說書人決定。
- 玩家錯誤使用能力（如僧侶選自己）時，立即提醒並請他重選。

## 提名

- 同一時間只有一個提名，前一個投票結束才能下一個。
- 只有**存活**玩家能提名；死者可以被提名。
- 每人每天最多提名一次、最多被提名一次。
- 可以提名自己。

## 投票

- 門檻：得票 ≥ 存活人數的一半（向上取整）。死者的票計入票數，但門檻只看存活人數。
- 計票從被提名者的**下一位**開始順時針進行，被提名者自己的票最後計。
- 死者只有一次投票機會（投票標記），投完就不能再投。

## 處決

- 「即將被處決」者：得票達門檻，且**高於**當天其他所有提名。
- 後來的提名票數更高，就取代原本的人選。
- 與目前最高票**同票**時，兩人都不處決；之後的提名必須超過這個票數才能成為人選。
- 每天最多處決一人；無提名、票數不足或平票，當天無處決。
- 處決後白天立即結束。
- **處決與死亡不同**：被處決不一定死亡（如受能力保護），死者也可以被處決，已死者不會再死一次。

## 勝負

- 善良：所有惡魔死亡。
- 邪惡：存活玩家只剩 2 人（不計旅行者）。
- 兩方同時達成時，善良獲勝。
- 惡魔死亡不一定結束遊戲（紅唇女郎接任）。
- 特殊勝負：聖徒死於處決（邪惡勝）、鎮長條件（善良勝）。

## 死亡

- 死亡立即失去能力與其持續效果，除非能力寫「即使你已死亡」或是死亡時觸發。
- 死者不能提名，只剩一次投票；仍隨陣營勝負；角色不公開。
- 黎明只宣布誰死亡，不說明原因。

## 醉酒與中毒

- 兩者互相獨立，效果相同：**失去能力，但本人不知道**，說書人照常讓他行動。
- 資訊類能力可以給錯誤資訊（通常應該給），但形式要合法，例如仍展示一個鎮民角色。
- 「每局限一次」的能力在毒醉時使用就算用掉。
- 能力在毒醉時觸發即浪費，之後恢復也不會重新生效。
- 持續性效果在毒醉期間失效，恢復後繼續；已生效的即時效果（如已造成的死亡）不撤銷。
- 毒醉的玩家**被別人探查**時不受影響，例如共情者仍能正確得知醉酒鄰居的陣營。
- 狀態屬於玩家，不屬於角色：換角色不會解除毒醉。

## 被當作（登記）

- 被當作某陣營或角色時，探查與只對該類型生效的能力會把他當作那樣處理，但**不會獲得該角色的能力**，真實陣營也不變。
- 由說書人在**每次**探查時決定，同一夜不同能力可以得到不同結果。
- 陣營與角色分開判定，可能出現「被當作善良的爪牙」或「被當作邪惡的外來者」。
- 暗流湧動中：**陌客**可被當作邪惡、爪牙或惡魔；**間諜**可被當作善良、鎮民或外來者；兩者死後仍有效。

## 角色或陣營改變

- 視為獲得新角色：立即有新能力，失去舊能力與其持續效果。
- 新能力若是「每局限一次」，即使之前有人用過，仍可用一次；若原本只在首夜生效，則在變化當晚生效。
- 角色與陣營獨立，改變其一不影響另一個。
- 得知自己角色或陣營改變不算獲取資訊，不受毒醉影響（酒鬼例外）。

## 說書人原則

- 讓遊戲有趣且公平，對毒醉的玩家盡量造成不利。
- 規則不清時先定下處理方式，告知玩家後一致執行。
